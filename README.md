# Machine Learning for Physical Systems: demos

Interactive browser demos for the lecture *Machine Learning for Physical Systems* (TUHH, winter semester 2026/27). Live site: https://alhermann.github.io/mlps-demos/

Each demo is a single self-contained HTML file that works offline. Short links of the form `https://alhermann.github.io/mlps-demos/go/<id>` are printed as QR codes on the slides and redirect to the demos.
